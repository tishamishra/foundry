How it works

  1. Download the master CSV — it has the full header and a few example rows.
  2. Paste it into ChatGPT with your prompts and ask it to fill more rows for one niche (one block per row). It keeps the same columns.
  3. Add the new rows to your file and upload it back here. Import routes each row to its niche's pool, skips anything already there, and reports what changed.

Columns: {{ columns|join(', ') }}. A row fills only the columns its kind needs — a faqs row uses question,answer; a reviews row uses name,text; a text block uses text; an about_paras row puts paragraphs in paras separated by ||.

Columns are matched by name, not position — any order works, extra columns are ignored, and you only need the columns a row actually uses. Headers are trimmed and case-insensitive.
