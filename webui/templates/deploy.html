Deploy

A site deploys only if it is shipped — it passed the QA gate and the SEO gate in the same build. Preview never asks that; deploy always does.

Credentials

Global — one GitHub account, one Cloudflare account. Written to data/secrets.yaml at 0600, added to .gitignore, and redacted out of every command line and log line this page shows. They are never rendered back here, so a field reads set or not set and nothing more.

An environment variable of the same name in capitals wins over the file, so a machine that should not hold credentials on disk does not have to.
